# Bookstore Management System

## Description
A Bookstore Management System developed using Java and Spring Boot.
The application provides REST APIs for managing books and bookstore-related operations.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST API

## Features
- Add books
- View books
- Update book details
- Delete books
- Manage book information
- REST API integration

## Project Structure
- Model
- Controller
- Service
- Repository
